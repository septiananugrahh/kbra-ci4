# Laragon

## Penggunaan
Laragon digunakan sebagai local development stack untuk KBRA.

## Komponen
- **Apache** — Web server
- **MariaDB 10.4** — Database server
- **PHP 8.2** — Runtime

## Konfigurasi
- Port default: 80 (Apache), 3306 (MariaDB)
- DocumentRoot: `d:\laragon\www\kbra-ci\public`

## Berkas Terkait
- `setup-obsidian.bat` — Setup script Obsidian + MCP + Copilot Instructions
- `.vscode/mcp.json` — MCP server config (Obsidian)
